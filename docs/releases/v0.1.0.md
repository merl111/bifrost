# Bifrost 0.1.0 — first Linux release

Two separate downloads for Linux x86-64:

- **Bifrost-0.1.0-x86_64.AppImage** — native CUI graphical workspace. Includes GTK; no Go, CUI checkout or GTK development packages required. Ubuntu 24.04/glibc 2.39 or newer, with X11 or XWayland.
- **bifrost-0.1.0-linux-x86_64** — standalone, statically linked CLI/TUI. No GUI libraries required.

```sh
chmod +x Bifrost-0.1.0-x86_64.AppImage
./Bifrost-0.1.0-x86_64.AppImage

chmod +x bifrost-0.1.0-linux-x86_64
./bifrost-0.1.0-linux-x86_64 --root /path/to/project tui
```

The GUI opens a project chooser. Use `--root /path/to/project` to open directly.
If FUSE is unavailable, use `APPIMAGE_EXTRACT_AND_RUN=1 ./Bifrost-0.1.0-x86_64.AppImage`.
Verify downloaded files with `sha256sum --check SHA256SUMS` after downloading all assets,
or check the matching line for the individual file you downloaded.

This first release includes concurrent conversation tabs, readable chat/tool activity,
project/repository navigation, file editing and terminals, provider/account/model selection,
context compaction, task monitoring, code walkthroughs, skills and MCP configuration.
Both frontends use the same Go services and persisted state.

This is an early release, not a declaration that the full roadmap is finished.
Provider credentials and optional tools (Git, vendor CLIs, browsers, SSH and hypervisors)
are configured separately. Live vendor/OAuth/VM compatibility is not established by fixture
checks. Native Wayland, ARM, macOS and Windows releases are not qualified here.
See [current build evidence](https://github.com/merl111/bifrost/blob/v0.1.0/docs/current-build.md)
and [desktop coverage](https://github.com/merl111/bifrost/blob/v0.1.0/docs/desktop.md).

Release gates run the Go race suites and vet, separate native Xvfb regressions, then launch
both delivered artifacts in a clean Ubuntu container without system GTK. Third-party notices
are included in the AppImage and the separate notices archive.
